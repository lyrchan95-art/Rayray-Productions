WORLD-FIRST GAME DESIGN (from World Weaving):
- Build the place before the mechanic: a 2-4 word world title, one line of backstory on the start screen, and a role for the player.
- First 60 seconds: one obvious action, one satisfying response, zero tutorial text. Teach by invitation: the first obstacle or layout makes the right move obvious.
- One odd, non-functional, handcrafted detail that suggests the world existed before the player (a sleeping cat on a rooftop, a sign with a pun).
- Every action answers back: screen shake, particle burst, number pop, navigator.vibrate (guarded).
- Difficulty is a curve, not a wall: each stage teaches then tests, and the next goal is visible.
- Open loop and persistence: keep something the player owns (best score, streak, unlocked item) in localStorage, greet a returning player, and end each run hinting at what unlocks next.
- One consistent visual language (flat shapes, pixel, or paper cut) and a quiet HUD that never fights the player.
- Use Hong Kong world flavour when the spec allows (landmarks, vocabulary).
